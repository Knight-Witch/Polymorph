## PFC-2026-09-12-027 — Fix framing preview parity and suppress Windows probe consoles

- Target files: `src/polymorph/models.py`, `src/polymorph/geometry.py`, `src/polymorph/probe.py`, `src/polymorph/ui/preview.py`, `src/polymorph/ui/adaptive_main_window.py`, `src/polymorph/ui/styles.py`, `src/polymorph/smoke_test.py`, `tests/test_geometry.py`, `tests/test_probe_fallback.py`, development version metadata, UX/architecture/adaptive-history/status docs, and required tracking files.
- Relevant history checked before editing: `PROJECT_CONTRACT.md`, `MASTER.md`, `PRE_FLIGHT_Check.md`, `CHANGELOG.md`, `docs/ARCHITECTURE.md`, `docs/UX_SPEC.md`, `HISTORY/REFERENCE_GIF_CONVERTER.md`, `HISTORY/DIAGNOSTICS/GIF_ADAPTIVE_MOTION_2026-09-10.md`, current `converter.py`, `adaptive_converter.py`, `geometry.py`, `filters.py`, `probe.py`, `preview.py`, base/adaptive main-window code, shared styles, packaged smoke test, and framing/probe tests.
- Human validation incorporated: a confirmed dev.15 Viper Favor-resolution run selected stride 2 and returned `2048x2048`, 188 frames over exactly 15.0 s, 82,147,387 bytes, with motion reported visually consistent. Two additional kitbash/decal-heavy 500-frame HeroForge variants also selected stride 2 and produced 250 perfectly uniform 80 ms frames at `1810x1810` and `1752x1752`. The adaptive requirement is therefore treated as satisfied and the adaptive algorithm is intentionally unchanged here.
- Diagnosis — console flashes: FFmpeg and gifski encode subprocesses already used Windows `CREATE_NO_WINDOW`; ffprobe did not. ffprobe is called when media is loaded and after encode passes for integrity verification, matching the user's focus-stealing popup timing exactly.
- Diagnosis — framing: export Crop/Fit already used FFmpeg `crop`/`pad` without deliberate stretching, but the animated preview maintained a separate geometry implementation. That duplication allowed the viewer to disagree visibly with export and made it impossible to trust the preview as the output framing reference.
- Diagnosis — selection styling: checked radio indicators were effectively invisible under the prior stylesheet, which caused a real testing mistake where Preserve motion looked like Favor resolution. This is a functional state-visibility defect, not merely aesthetic polish.
- Recommended action: suppress ffprobe consoles on Windows; centralize Original/Crop/Fit calculations in `native_geometry_for_size()` and consume that geometry from both encoder and preview; add Crop-only 100–300% zoom that shrinks the retained source crop window rather than upscaling; keep Fit as aspect-preserving padding; make checked radio state explicit; gate the behavior with unit and packaged-app smoke tests.
- Connected modules reviewed: FFmpeg filter construction, no-upscale validation, linked fixed-resolution controls, Crop/Fit drag offsets, preview QMovie rendering, post-encode probing/integrity verification, adaptive diagnostic worker, packaged PyInstaller smoke, installer/version metadata.
- Conflict risks: changing framing math could regress export behavior; crop zoom could accidentally violate no-upscale; a new control could reintroduce right-rail compression; hiding subprocess windows could obscure errors; Qt/PyInstaller can round-trip str-backed Enum combo data as plain strings rather than preserving Python object identity.
- Safeguards: FFmpeg filter construction continues to consume the same shared geometry object; zoom changes crop dimensions instead of scaling source pixels upward; ffprobe stdout/stderr remain captured even with `CREATE_NO_WINDOW`; framing combo data is normalized through `FramingMode(...)` instead of identity tests; Preserve-motion GIF, adaptive stride policy, MP4, size optimizer, updater, and pinned toolchain are untouched.
- Tracking rollover: the growing pre-flight/changelog histories are archived verbatim under `HISTORY/PROJECT_LOGS/` before this entry so no prior project record is deleted while the active tracking files remain manageable.
- Versioning: increment development tester from `0.1.0-dev.15` to `0.1.0-dev.16`.
- Unchanged: adaptive candidate order/8% gain gates/2048px soft target and exact timing policy; Preserve-motion GIF; MP4; 99 MB decimal ceiling; gifski 1.32.0; FFmpeg 9.0.1; updater behavior; public-release state.
