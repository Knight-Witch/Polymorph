# Packaged Third-Party License Texts

The official Windows release pipeline populates this directory with exact license texts for the third-party runtime/build components distributed with Polymorph.

Expected release files:

- `GPL-3.0.txt` — FFmpeg GPLv3 build and the GPL text incorporated by LGPLv3.
- `AGPL-3.0-gifski.txt` — gifski 1.32.0 license and AGPLv3 terms.
- `LGPL-3.0-Qt.txt` — Qt/PySide6 LGPLv3 terms.
- `PYTHON-3.12.10.txt` — CPython license and historical notices.
- `PYINSTALLER-6.22.3.txt` — PyInstaller licensing terms and Bootloader Exception.
- `OPENSSL-3.0.16.txt` — OpenSSL Apache 2.0 license.

Font and Lucide notices are also bundled inside `polymorph/assets` with the application.

See `THIRD_PARTY.md` for the component inventory and `THIRD_PARTY_SOURCE.md` for exact source availability.
